Robot Framework Essentials is a hands-on course in eight parts. It starts with your first
suite and ends with running Robot Framework in CI. Each lesson pairs a short concept with
tasks you do in your own VS Code workspace, then a quiz and the lesson's key terms.

## Before you start

1. Read [How this course works]({{base}}/ch00-orientation/how-to-use-this-course/).
2. Pick how you run Python and get the labs:
   [Labs & choosing how you run]({{base}}/ch00-orientation/initializing-and-choosing-your-setup/).
3. Start with [What Robot Framework is]({{base}}/ch01-introduction/what-robot-framework-is/).

You need Python {{python}} or newer and one environment manager: uv (recommended, and it
installs Python {{python}} for you when it is missing), venv, or poetry. Install the **RobotCode** extension in VS Code for syntax highlighting, running and
debugging. Part 2 (Web Testing) also needs Node.js.

From chapter 2 on, every chapter has a lab: a small, ready-to-run project you download
as a `.zip`, open in VS Code and set up with one command. The starter kit below holds all
labs at once.

Quiz answers, ticked tasks and your runner choice stay in this browser. Nothing is sent
anywhere.
