# How this course works

This course is hands-on: you learn Robot Framework by doing it in your own editor.
Each lesson mixes short reading with tasks you carry out in VS Code. This first
chapter is a quick tour of the pieces you'll meet. There is nothing to install yet.

> **Note:** This is the web edition. The Robot Framework Essentials extension for
> VS Code runs the same course and checks your work for you; here, you check it
> yourself against the "Done when" line of each task.

## Reading, and the three callouts

Most of a lesson is plain reading like this. Watch for three highlighted notes:

> **Note:** Background or context worth knowing.

> **Tip:** A shortcut or good habit.

> **Warning:** A common mistake to avoid.

## Tasks and "Done when"

A lesson is a short list of **tasks**. Each task heading carries a badge for its
kind: **edit** (write or change a file), **run** (run a command), or **read**. A task
ends with a **Done when** line that states what to verify in your workspace, usually
that a suite passes or a file exists. When it holds, tick **Done** on the task; the
tick is how this site tracks your progress.

## Writing code — worked example and hints

Later, some tasks ask you to **write** something — a suite, a keyword, a variable.
These show a **goal** (what to build, not the code) and a runnable **worked
example** over different data to adapt rather than copy. If you get stuck, a **hint
ladder** reveals help one rung at a time, and its final rung is the full solution —
so you always have a way forward. Your first real build-task arrives in the next
chapter.

## Running commands

A command appears in a code block with a **Copy** button. Paste it into a terminal
in VS Code (**Terminal → New Terminal**) opened in your lab folder:

```bash
echo "Ready for Robot Framework."
```

Some lessons also *show* a command running, as a short replay you can watch and
re-play:

```terminal
$ robot --version
Robot Framework 7.4.2 (Python 3.13 on linux)
```

## Quizzes

A short **quiz** closes every lesson — like the one below. Pick an answer and the
explanation shows the reasoning either way. Your first answer stays in this browser,
and quizzes never block your progress.

## Your progress

The sidebar lists every part, chapter, and lesson; **Previous** and **Next** at the
bottom of each page follow the course order. Each part's overview page shows which
lessons you have finished, and every lesson's key terms collect in the
[Glossary]({{base}}/glossary/).

Ticks, quiz answers, and your runner choice are stored in this browser only. Another
browser or cleared site data starts fresh, and the
[course overview]({{base}}/) can reset them.

That's the whole format. Answer the quick check below, then continue with the setup
lesson.
