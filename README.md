# Robot Framework Essentials — web edition

A hands-on [Robot Framework](https://robotframework.org/) course in eight parts, from your
first suite to running Robot Framework in CI, published at
**https://manykarim.github.io/robotframework-essentials-web/**.

Each lesson pairs a short concept with tasks you do in your own VS Code workspace, then a
quiz and the lesson's key terms. From chapter 2 on, every chapter has a lab: a small,
ready-to-run project you download as a `.zip` and set up with one command (uv, venv or
poetry). Quiz answers, ticked tasks and your runner choice stay in your browser.

The site is built with [Astro Starlight](https://starlight.astro.build/).

## Local development

Requires Node.js 22 or newer (the workflow uses Node 22).

```sh
npm ci                 # install exactly what package-lock.json pins (from registry.npmjs.org)
npm run dev            # live preview at http://localhost:4321/robotframework-essentials-web/
npm run test:ci        # type check, production build with link validation, unit tests
npm run preview        # serve the production build at http://localhost:4321/robotframework-essentials-web/
npm run smoke -- http://localhost:4321/robotframework-essentials-web   # serving checks
```

## Repository layout

| Path | What |
| --- | --- |
| `src/content/docs/` | All pages of the site (generated by the importer) |
| `src/rfe/generated/course.json` | Course order, sidebar, labs and glossary (generated) |
| `labs/` | Lab sources, packaged into the `.zip` downloads (generated) |
| `src/rfe/overrides/`, `src/rfe/rewrites.json`, `src/rfe/templates/` | Web-edition wording on top of the course source |
| `src/rfe/markdown/`, `src/rfe/components/`, `src/rfe/client/`, `src/rfe/styles/` | Lesson rendering, page components, browser scripts, theme |
| `src/pages/labs/[lab].zip.ts` | Builds the lab downloads |
| `scripts/rfe-import.mjs` | Regenerates the generated files from the course source |
| `site.config.mjs` | Site URL and base path |

## Updating the course

The lessons come from the course source repository `rf-training-platform`, which also
builds the VS Code edition of the course. With a checkout of it next to this repository:

```sh
node scripts/rfe-import.mjs ../rf-training-platform
npm run test:ci
```

Commit the regenerated files together with the change. [AGENTS.md](AGENTS.md) describes
the importer, the overrides and the lesson Markdown dialect in detail.

## Deployment

Every push to `main` runs the checks in GitHub Actions and publishes the site to GitHub
Pages. Pull requests run the checks without deploying.
